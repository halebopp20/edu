## 1. 배경 및 목표

기존 앱은 1단계(객관식)와 2단계(전체 쓰기) 두 가지 모드를 수동으로 선택하는 구조였다. 아이가 객관식은 잘 풀지만 전체 쓰기는 너무 어려워 한 문제도 못 풀었다. 목표:

- 객관식 → 전체 쓰기 사이에 중간 단계를 두어 자연스럽게 스펠링 쓰기로 유도
- 단어별 숙달 진행 상황을 별점으로 시각화 (정원 성장 테마)
- 전체 단어 숙달 시 수료증 + 비밀코드로 엄마한테 칭찬/선물 연결

---

## 2. 학습 단계 구성 (4단계)

각 단어는 독립적으로 1→2→3→4단계를 밟는다. 모든 쓰기 단계는 캔버스 손글씨.

| 단계 | 이름 | 방식 | 채점 |
|------|------|------|------|
| 1단계 | 객관식 | 뜻 보고 보기 4개 중 고르기 | 자동 채점 |
| 2단계 | 보면서 쓰기 | 정답 단어를 크게 보여주고 캔버스에 따라 쓰기 | 자가 채점 |
| 3단계 | 힌트 보고 쓰기 | 앞 `ceil(글자수/2)`자만 힌트 표시 (예: "force"→`fo_ _ _`, "aim"→`a_ _`), 캔버스에 전체 단어 쓰기 | 자가 채점 |
| 4단계 | 완전 암기 | 뜻만 보고 캔버스에 전체 단어 쓰기 | 자가 채점 |

### 자가 채점 흐름 (2·3·4단계 공통)

1. 캔버스에 손으로 쓰기
2. "정답 확인" 버튼 → 정답 단어 크게 표시
3. **✅ 맞았어요** → 별 +1 즉시 저장, 이번 세션에서 해당 단어는 종료 (다음 세션에서 새 단계로 등장)
4. **🔁 다시 볼게요** → 현재 단계 유지, 이번 세션 내 남은 단어들이 끝난 후 1회 재등장

---

## 3. 세션 진행 방식 (단어별 독립 진행)

- 세션 시작 시: 별 4개 미만인 단어들을 현재 단계로 퀴즈 (섞어서)
- **한 세션에서 한 단어를 4단계 연속으로 하지 않는다** — 단어들이 인터리브(interleave)되어 나옴
- 맞은 단어: 별 +1, 다음 세션에서 다음 단계로
- 틀린 단어: 현재 단계 유지, 같은 세션 끝에 1회 재시도 기회
- 별 4개(4단계 통과) = 완전 숙달 → 이후 세션에서 제외

### 예시 흐름

**세션 1** (모든 단어 별 0개):
```
allow → 1단계(객관식) → 맞음 → 별 1개
bitter → 1단계 → 틀림 → 세션 끝에 재도전
common → 1단계 → 맞음 → 별 1개
...
```

**세션 2**:
```
allow → 2단계(보면서 쓰기)
bitter → 1단계(지난번 틀림, 재도전)
common → 2단계(보면서 쓰기)
...
```

## 4. 별점 & 정원 시각화

### 단어별 별점
- 각 단계 통과 시 별 1개 획득 → 최대 4개
- 별점은 localStorage에 단어별로 저장

### 홈 화면 정원 격자
- 20칸 격자로 전체 단어 진행 상황 표시
- 별점에 따라 이모지 성장:

| 별점 | 이모지 | 의미 |
|------|--------|------|
| 없음 (미시작) | 🌱 (흐리게, opacity 0.25) | 아직 한 번도 안 봄 |
| ⭐☆☆☆ | 🌱 | 1단계 통과 |
| ⭐⭐☆☆ | 🌿 | 2단계 통과 |
| ⭐⭐⭐☆ | 🌷 | 3단계 통과 |
| ⭐⭐⭐⭐ | 🌸 | 완전 숙달 |

### UI 변경 사항
- 기존 "Unit 1 / Unit 2 선택" 칩 **제거** → 항상 전체 20개 대상
- 시작 버튼에 "오늘의 연습 (N개 남음)" 형태로 미숙달 단어 수 표시

## 5. 수료증 & 비밀코드

20개 단어 전부 별 4개 달성 시 수료증 화면 표시:

- 꽃 20송이 가득 찬 정원 이미지
- 수료증 텍스트: "이 친구는 초록 단어 정원의 모든 꽃을 피웠습니다 🌸"
- **비밀코드** 공개 (예: `ROSE🌸`)
  - HTML 파일 상단 `var SECRET_CODE = "ROSE🌸";` 한 줄로 엄마가 직접 설정
  - 아이가 엄마한테 코드를 말하면 선물/칭찬 약속
- "엄마한테 보여주기" 버튼 (스크린샷 유도)
- "처음부터 다시 하기" 버튼 (별점 초기화)

## 6. localStorage 데이터 구조

```javascript
// 키: "vwgreen_progress_v3"
{
  "theme": "light",          // 기존 유지
  "words": {
    "allow":  { "stars": 4 },  // 0~4
    "bitter": { "stars": 1 },
    "common": { "stars": 0 },
    // ... 20개 단어 전부
  }
}
```

- 기존 `vwgreen_progress_v2` 키와 충돌하지 않도록 `v3`로 새 키 사용
- `stars` 값이 곧 현재 단계 (stars=0 → 1단계 시도, stars=1 → 2단계 시도, ...)

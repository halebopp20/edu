# Article Quest — Design Spec

**날짜:** 2026-10-15
**대상:** 초등 저학년 (영어 문법 학습 중인 아이)

---

## 1. 배경 및 목적

아이의 오답 분석 결과, 두 가지 핵심 약점이 확인됨:

| 약점 | 구체적 오류 |
|------|------------|
| Count vs Noncount 구분 불안정 | bread·oil·cheese·milk를 Count로 오인 → `a cheese`, `an milk` |
| `the` — Specific 개념 미흡 | 앞 문장에서 언급된 명사에 `the`를 써야 할 때 "Only one thing"으로 잘못 분류 |

말로 반복 설명해도 효과가 없어, **인터랙티브 훈련 앱**으로 반사 회로를 만드는 것이 목적.

---

## 2. 앱 개요

- **파일:** `english/article-quest.html` (단일 HTML 파일)
- **테마:** 다크 초콜릿 🍫 (진한 브라운 배경 + 골드/크림 텍스트)
- **모드:** Sort(분류) + Drill(드릴) 인터리브 방식

---

## 3. 학습 콘텐츠

### 3-1. 커버하는 문법 개념

| 개념 | 규칙 요약 |
|------|----------|
| `a` vs `an` | 모음 소리(a·e·i·o·u) 앞 → `an`, 자음 소리 앞 → `a` |
| Count vs Noncount | 셀 수 있는 명사 → `a/an`, 셀 수 없는 명사 → `some` |
| `some` | Noncount 명사 또는 복수 가산명사 앞 |
| `the` (only one) | 세상에 하나뿐인 것 (sun, moon, sky, sea) |
| `the` (specific) | 앞 문장에서 이미 언급된 명사를 다시 가리킬 때 |

### 3-2. Sort 문제 — 단어 목록 (예시)

| 단어 | 분류 | 이모지 |
|------|------|--------|
| milk | Noncount | 🥛 |
| cheese | Noncount | 🧀 |
| bread | Noncount | 🍞 |
| oil | Noncount | 🫙 |
| water | Noncount | 💧 |
| apple | Count | 🍎 |
| book | Count | 📚 |
| cat | Count | 🐱 |
| bicycle | Count | 🚲 |
| banana | Count | 🍌 |

### 3-3. Drill 문제 — 문장 목록 (예시)

| 문장 | 정답 | 힌트 |
|------|------|------|
| I drink ___ milk. | some | milk은 셀 수 없어요 → some! |
| She has ___ umbrella. | an | u로 시작하는 소리 → an! |
| Look at ___ sun. | the | 태양은 하나뿐이에요 → the! |
| Tom has a dog. ___ dog is cute. | The | 앞에서 말한 그 강아지 → The! |
| We need ___ onion. | an | o로 시작하는 소리 → an! |
| I need ___ cheese. | some | cheese는 셀 수 없어요 → some! |
| Jack has ___ smartphone. | a | s는 자음 소리 → a! |
| ___ sky is clear. | The | 하늘은 하나뿐이에요 → The! |
| She has a cat. ___ cat is small. | The | 앞에서 말한 그 고양이 → The! |
| I see ___ elephant. | an | e로 시작하는 소리 → an! |

## 4. 게임 구조

### 4-1. 마스터리 기반 루프

```
전체 문제 큐 생성 (Sort + Drill 교차)
  └─ 문제 출제
      ├─ 정답 → 큐에서 제거
      └─ 오답 → 정답 표시 후 큐 맨 뒤에 재추가
          └─ 큐가 빌 때까지 반복
              └─ 모두 정답 → 엔딩
```

- 진행 바: "남은 문제 N개" 실시간 표시
- 틀린 문제는 정답을 확인한 직후 재추가 (즉시 반복 아님, 간격 두고 재출제)

### 4-2. 인터리브 순서

```
Sort → Drill → Sort → Drill → Sort → Drill → ...
```

한 턴씩 교대. 오답 재추가 규칙:
- Sort 문제 오답 → Sort 큐 맨 뒤에 재추가
- Drill 문제 오답 → Drill 큐 맨 뒤에 재추가
- 두 큐를 번갈아 소진하므로 인터리브 패턴 자연스럽게 유지됨
- 한 쪽 큐가 먼저 소진되면 남은 큐만 처리 후 종료

## 5. 화면 설계

### 5-1. 홈 화면

- 앱 제목: "🍫 Choco Quest"
- 부제: "Master a, an, the & some!"
- Start Quest 버튼
- 최고 기록 표시 (첫 시도 정답률 기준, localStorage)

### 5-2. 게임 화면 — Sort 턴

- 상단: 진행 바 ("남은 문제 N개")
- 단어 카드 1개 (단어 + 이모지, 크게 표시)
- 바구니 2개 (클릭으로 선택, 드래그 없음):
  - 📦 **Count** → a / an
  - 💧 **Noncount** → some
- 정답 시: 초록 테두리 + "✓ Noncount!" 메시지 → 1.5초 후 다음
- 오답 시: 빨간 테두리 + 정답 강조 표시 → 2초 후 다음

### 5-3. 게임 화면 — Drill 턴

- 빈칸 문장 (큰 폰트, 가독성 우선)
- 보기 버튼 4개: `a` / `an` / `the` / `some`
- 정답 시: 골드 버튼 강조 + 짧은 힌트 문장 → 1.5초 후 다음
- 오답 시: 흔들림 애니메이션 + 정답 버튼 강조 + 힌트 → 2초 후 다음

### 5-4. 엔딩 화면

**1단계 — 아이용 축하:**
- 전체화면 골드 폭죽 CSS 애니메이션
- "🍫 Choco Master! All Clear! 🏆"
- 별 3개 ★★★
- 총 시도 횟수 표시

**2단계 — 부모 확인 (버튼 클릭 시):**
- "부모님께 보여주기 📣" 버튼
- 클릭 시 성취 요약 카드:
  - 총 문제 수
  - 첫 시도 정답률 (%)
  - 가장 많이 틀린 개념 (예: "the — Specific 3번 틀림")
  - 완료 시각

## 7. 기술 사항

- **단일 HTML 파일** — 외부 의존성 없음 (기존 앱들과 동일)
- **localStorage** — 최고 기록 저장
- **CSS 애니메이션** — 폭죽 효과, 흔들림, 정답/오답 피드백
- **모바일 대응** — 클릭 방식 (드래그 없음), 큰 버튼
